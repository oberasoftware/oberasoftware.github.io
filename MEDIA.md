- `assets/products/haven/key-art.jpg` and `icon.png`: optimized derivatives of the owner's original `tower_defense/game/Assets/CitadelCoin/Branding/AppIcon.png`. They are labeled artwork, not gameplay.
- `assets/products/haven/01…04-*.jpg`: web-size JPEG derivatives of the actual native iOS simulator screenshots in `tower_defense/docs/release-package/screenshots/ipad/`. Captured 24 November 2026 from earned first-land campaign states in simulator build 1.0 (41); same gameplay/art as device candidate 1.0 (42). Resized and compressed only; no fabricated gameplay or retouching. PNG originals and state hashes remain in the game repository release package.
- `assets/products/jasdb/document-engine.svg`: original editable vector illustration made for this site. Represents documents/indexes and Java/REST access, not a product UI screenshot or benchmark.
- `images/oberalogo.png`: original 200×66 handwritten Obera wordmark and red comet, retained unchanged from the legacy website. Displayed at or below native size in the heritage panel.
- `assets/publishing/mark.svg`: editable vector interpretation of that original comet’s swept silhouette and separated tail strokes. Retains the red identity with a brighter red for the dark header; not a replacement for the archived original.
- `assets/publishing/favicon.svg`: compact diagonal arrangement of the same vector comet, on the publisher background.
- Typography uses installed system fonts. No remote font requests or new font licenses.
- Legacy files outside `assets/products/` and `assets/publishing/` are retained for compatibility; new publisher pages do not load them.
